# 🚀 Quick Start - Clonador de Sites

## ⚡ Início Rápido (3 passos)

### 1️⃣ Instalar Ruby
Baixe e instale: https://rubyinstaller.org/downloads/
- Escolha: **Ruby+Devkit 3.2.x (x64)**
- ✅ Marque: "Add Ruby executables to your PATH"

### 2️⃣ Instalar Nokogiri
Abra o PowerShell e execute:
```bash
gem install nokogiri
```

### 3️⃣ Usar o Script
```bash
# Teste básico
ruby clone_site.rb

# Clonar um site específico
ruby clone_site.rb https://www.exemplo.com
```

## 📖 Documentação Completa

- **README.md** - Visão geral e funcionalidades
- **INSTALACAO.md** - Guia detalhado de instalação
- **clone_site.rb** - O script principal

## 🎯 Exemplos de Uso

```bash
# Clonar Wikipedia
ruby clone_site.rb https://pt.wikipedia.org

# Clonar um blog
ruby clone_site.rb https://meublog.com.br

# Clonar uma landing page
ruby clone_site.rb https://minhaempresa.com
```

## 📁 Resultado

Cada execução cria uma pasta:
```
cloned_site_1234567890/
├── index.html
├── css/
├── js/
└── images/
```
